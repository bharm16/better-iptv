# Agent instructions

Be direct and critical in your feedback. If you see a better approach,
suggest it immediately. Challenge assumptions when warranted.

## Agent skills

### Issue tracker

Issues live as local Markdown files under `.scratch/<feature>/`.
See `docs/agents/issue-tracker.md`.

### Triage labels

Use the five default triage roles.
See `docs/agents/triage-labels.md`.

### Domain docs

Single-context layout: root `CONTEXT.md` and `docs/adr/`.
See `docs/agents/domain.md`.
