# Device owns personalization in the first release

Favorites, recent channels, and channel organization are saved on the TV and retained across app and TV restarts; the first public release requires no app account and does not synchronize that state between devices. This prioritizes reliable continuity on each TV and a focused initial release over automatically carrying preferences to another device. The phone-to-TV setup handoff is a separate decision and does not establish a cloud account or cloud credential-storage requirement.
